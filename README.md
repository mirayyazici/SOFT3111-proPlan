# proPlan — SOFT3111 Project #1 

**Kapsam:** Işık Üniversitesi için ilk sürüm, daha sonra diğer üniversitelere uyarlanabilir mimari.

## İçerik
- `01_Project_Proposal/ProjectProposal.docx` — güncellenmiş İngilizce proje önerisi (kapak dahil 6 sayfa).
- `01_Project_Proposal/ProjectProposal.pdf` — aynı belgenin PDF karşılığı.
- `02_Interactive_HTML/index.html` — 10 ekranlı, yerel olarak açılabilen etkileşimli HTML prototipi.
- `03_Figma_Screen_Sketches/ScreenSketches_10_Pages.pdf` — 10 ekranın tarayıcı görüntüleri.
- `03_Figma_Screen_Sketches/PNG_Previews/` — 10 masaüstü ekranı ve mobil kayıt örneği.
- `03_Figma_Screen_Sketches/Editable_SVG/` — Figma'ya aktarılabilir metin/şekil tabanlı SVG taslakları (HTML ile tamamen aynı DOM davranışlarını içermez).
- `03_Figma_Screen_Sketches/Screen_Flow.svg` — temel öğrenci/admin akışı.
- `04_Documentation/` — proje kapsamı, Figma eşitleme notu, tarayıcı testleri ve teslim kontrol listesi.

## Başlangıç
`02_Interactive_HTML/index.html` dosyasını Chrome/Edge/Firefox'ta açın. Harici sunucu veya .NET kurulumu gerekmez. Demo hesapları:
- Öğrenci: `demo.student@isik.edu.tr` / `Demo1234`
- Yönetici: `demo.admin@isikun.edu.tr` / `Admin1234`

**Bu demo hesaplar gerçek üniversite hesabı değildir.** e-Campus istekleri, transcript/CAR/CCR verileri, AI yanıtı ve ders planı hesaplaması bu pakette simülasyondur.

## Figma
